# GDD — 타이핑버스 3D·학교 순위 강화 계획서 (2026-10-20)

> 사용자 지시(2026-10-20): «타이핑버스는 학교부터 전체 다 · 게임 부분 3D 로 · 강화».
> 조사 = `docs/research-3d/`(GPT 15+8종 · Gemini · Grok · 3D/2.5D 타자 게임 실존 확인 · 가독성·저사양 규칙).
> 범위: **게임 6종 화면만 3D**(연습·시험·도전·통계·상점 페이지는 지금 2D 그대로) + **학교 순위** + 기본틀 + 이야기·성장 층.

## 0. 한 줄
**글자는 2D 로 또렷하게, 세상은 3D 로.** 3D 장면(Three.js) 위에 입력할 단어는 «화면과 평행한 HTML 라벨»로 띄운다. 6종을 한 번에 바꾸지 않고 **«산성비 → 씨앗비»를 먼저 3D 로 만들어 학교 PC급에서 잰 뒤** 나머지 5종으로 넓힌다.

## 2. 6종 3D 장면 (게임 규칙·점수식은 그대로 — 화면만 바뀐다)
| 순서 | 지금 | 3D 장면 | 카메라 | 단어 붙는 곳 |
|---|---|---|---|---|
| **1(시험)** | 산성비 | **씨앗비** — 구름 섬에서 씨앗 캡슐이 레인 5줄로 내려오고, 완성하면 화분으로 날아가 꽃이 핀다 · 바닥에 닿으면 흙이 시든다 | 고정 정면 사선 20° | 캡슐 위 라벨 |
| 2 | 우주 방어 | 우주 통로에서 다가오는 **고장 난 드론** — 글자마다 수리 광선, 완성 시 드론이 살아나 편대에 합류 | 고정 후방 | 드론 위 라벨 |
| 3 | 좀비 서바이벌 | 해 질 녘 놀이터로 다가오는 **슬라임** — 완성하면 정화돼 친구로 돌아간다 | 고정 사선 45° | 슬라임 위 라벨 |
| 4 | 킹덤 디펜스 | 디오라마 성과 길 — 길을 따라 오는 장난감 군대를 단어로 막는다(경로·탑 규칙 그대로) | 고정 아이소 | 유닛 위 라벨 |
| 5 | 타이핑 레이스 | 디오라마 트랙의 장난감 자동차 3대 — 정확히 칠수록 전진 | 측후방 추적(흔들림 0 · 보간) | **하단 고정 문장**(차 위 라벨 없음 — TypeRacer 관습) |
| 6 | 끝말잇기 | 공중 블록 섬 — 이은 단어마다 다리 블록이 놓여 섬을 건넌다 | 고정 사선 | 정면 카드(고정) |
- 각 종 규칙·단어 출제·점수·리그 정산은 지금 코드를 **그대로** 쓴다(게임 로직 = 기존 · 렌더만 교체). 로직이 페이지 컴포넌트 안에 섞여 있으면 먼저 `src/lib/game/<종>/core.ts` 로 떼어 낸다(로직·렌더 분리 HARD · 시험 대상).
- **WebGL2 없는 기기 = 지금 2D 게임 그대로**(폴백 · 설정에서 «가벼운 화면»으로 직접 고를 수도).

## 3. 학교 순위 (kit/school-hub · 기본틀)
| 항목 | 결정 |
|---|---|
| 허브 | `install.sh --id typingverse --host pages --store do --free-play --deploy` — 판 자체가 타자 연습이라 «문제 풀고 이용권» 화면 없음(free-play: 판 영수증·학교 점수·하루 상한만) · DO 저장소(D1 자리 아낌) |
| 연결 | **직결**(`configureHub({ direct })` — Pages 함수 공용 한도 무관) |
| 학교 점수 | 판 끝 `gbFinish` — 정확도 ≥ 90% 판만 +1 · 기기 하루 상한(키트 기본) |
| 화면 | 홈 맨 위 학교 순위 카드(상위 5 + 우리 학교 · 전체 보기 · 참여 학교/기기 통계) · 게임 목록 위 |
| 기존 순위·리그 | 그대로 둔다(개인 타수 순위 = 기존 · 학교 순위 = 새 카드) |
| 학교 고르기 | 키트 «학교 찾기»(실은 목록 6,330곳 · 외부 나이스 호출 0) · 기기에 저장 |

## 4. 개인정보 정리 (HARD — `children-privacy-and-safety.md`)
- 🔴 지금 닉네임 = **자유 입력**(금칙어 필터) → 스킬 HARD «자유 입력 이름 필드 0개» 위반.
  **바꾼다**: 가입·이름 바꾸기 화면을 **생성 닉네임 고르기**(형용사×명사×숫자 — 서버 화이트리스트 재검증)로 교체.
  기존 계정: 점수·리그·지갑은 그대로, 공개 목록(순위·리그·고스트)에 나가는 이름만 생성 닉네임으로 **치환**(본인 화면엔 «새 이름으로 바뀌었어요» 1회 안내).
- 학교 = 목록에서 고르기만(NEIS 코드) · 공개 화면엔 학교별 합계만(학교 안 개인 순위 없음).

## 5. 이야기·성장 층 (`kit/story` · 🔒 `check-story --require`)
| 인물 | 역할 | 표정 |
|---|---|---|
| **타비**(지금 마스코트 재사용·리그) | 동반자 — 버스 운전사 꼬마 로봇. 손끝으로 «글자 버스»를 움직인다 | 기쁨·놀람·시무룩·결의(4) |
| **잉크 망토** | 악역 — 글자를 지워 세상을 조용히 만들려는 망토 · 사연: 말을 더듬어 놀림받은 뒤 글자가 싫어졌다 | 심술·당황·눈물·웃음(4) |
| 정류장 NPC 6명 | 게임 6종 = 버스 노선 6정류장(씨앗섬·우주 정거장·놀이터·성·트랙·블록섬) 주인 | 각 3 |
- 프롤로그(첫 실행 · 3줄 + 선택지): 잉크 망토가 정류장 글자를 지웠다 → 타비 «글자를 쳐서 노선을 다시 잇자!».
- 정류장(게임)마다 별 문턱(판 결과 → 별)으로 관계 조각 1~3줄 · 마지막 = 잉크 망토 화해(«내 말도 기다려 줄래?»).
- 성장 재료 = **정확도·타수 결과(별)** — 상점 구매로는 안 큰다. 타비 버스 4단계(마을 버스 → 2층 버스 → 날개 버스 → 별빛 버스) · 3D 장면 안 버스 모델도 바뀐다(외형만).
- 판 안 대화창 0 — 판 사이·홈에서만, 건너뛰기 항상. 판 안은 정류장 NPC 말풍선(판을 멈추지 않음).

## 6. 타격감 (juice v3)
- 지금 `hit` 행동이 HIT 묶음(0.1초 멈춤·찌그러짐+튕김·kick·하얀 번쩍)을 못 갖춰 `check-juice` FAIL → 3D 판에서 **`HIT_3D`**(줌 펀치 kick · emissive 번쩍 · 대상 squash+knock · 파편 · 숫자 · 소리)로 맞춘다.
- 단, **입력 중인 단어 라벨은 흔들지 않는다**(가독성 규칙 6) — 흔들림은 3D 장면 캔버스만.

## 7. 기본틀 나머지
- 전체화면 단추 + 게임 들어가면 자동 전체화면.
- 모드 4종 이상: 게임마다 classic(지금) + time(60초 타임어택) + survival(끝없이·목숨 3) + daily(오늘의 단어 묶음 — 날짜 시드). 레이스는 classic·time·daily.
- 🔴 이모지 160곳 → 자체 SVG 아이콘(lucide-react 이미 의존성) · 🔒 `check-no-emoji` PASS.

## 8. 완료 기준 (DoD — 각 줄 = 시험 하나)
### A. 3D 판(6종 공통 — 씨앗비부터)
- [ ] 단어 라벨은 화면과 평행하고, 1280×720 에서 글자 높이 ≥ 24px · 가장 먼 대상도 같다
- [ ] 동시에 보이는 단어 라벨 수 ≤ 난이도 상한(4/5/6) · 라벨 사각형끼리 겹침 0
- [ ] 입력 중 카메라 위치·각도가 변하지 않는다(타격 kick 은 단어 완성 후 0.2초)
- [ ] 한글 조합 중(ㅎ→하→한) 오타 판정 0 · 영문은 확정 글자만 진행 — 기존 판정 시험 그대로 통과
- [ ] 게임 로직 시험: 2D 판과 3D 판이 같은 시드·같은 입력열에서 점수·정확도·타수가 같다(렌더만 바뀜)
- [ ] WebGL2 를 끄면 지금 2D 게임이 뜬다
- [ ] 판을 나갔다 들어와도 geometry·texture 수가 늘지 않는다(dispose · renderer.info)
- [ ] 콘솔 에러 0
### B. 학교·개인정보
- [ ] 홈 맨 위 학교 순위 카드가 10초 안에 뜬다(«불러오지 못했어요» 0 — gate-baseline B10)
- [ ] 정확도 ≥90% 판만 학교 점수 +1 · 판 하나 = 영수증 하나
- [ ] 이름 자유 입력 칸 0개 · 공개 목록 이름 = 전부 생성 닉네임 형식
- [ ] `check-server-cost` PASS — 글자마다 요청 0 · 15초 미만 폴링 0
### C. 이야기·기본틀·게이트
- [ ] 프롤로그·정류장 조각·화해가 별 문턱대로 열리고 앨범에서 다시 본다 · 판 안 대화창 0
- [ ] 모드 4종(레이스 3종) 카드 · 전체화면 자동
- [ ] `check-no-emoji` · `check-juice --require` · `check-story --require` · `gate-char-rig` · `check-image-engine` · `gate-3d-source` · `gate-baseline --expect-hub` PASS
- [ ] 배포본(typingverse.pages.dev)에서 6종 각각 첫 판을 실제로 쳐서 끝까지(e2e)

## 9. 성능 예산 (합격선 = 참조 기기 + 해상도 + P95)
| 항목 | 상한 |
|---|---|
| 참조 기기 | 크롬 CPU 4배 감속 + `--use-angle=swiftshader`(소프트웨어 GL — 내장 GPU 최악 대리) · 3D 캔버스 1280×720 · DPR 1 |
| 최악 장면 | 단어 6개 + 대상 20 + 파편 150 + 라벨 6 |
| 프레임 | **P95 ≤ 16.7 ms**(GPU 경로) · swiftshader 는 P95 ≤ 33.3 ms(경고선) — rAF 간격으로 잰다 |
| 구조 경고선 | 드로 콜 ≤ 50 · 삼각형 ≤ 100k · 텍스처 ≤ 24MB VRAM |
| 전송량 | three(≈303 KiB br) + 게임별 장면은 **그 게임 들어갈 때만** 지연 로드 · 게임 하나당 모델·텍스처 ≤ 1.5 MB |
| 3D 모델 | Firefly 3D(🔒 gate-3d-source) · 캐릭터 = 리그(타비·잉크 망토·슬라임·드론) |

## 10. 작업 순서
1. 개인정보(생성 닉네임) + 학교 허브 설치·직결 + 홈 학교 카드 + 이모지 → SVG
2. 이야기·성장(kit/story · 초상화) + 모드 묶음 + 전체화면
3. **씨앗비 3D** — 로직 분리 → 3D 장면 → 라벨 → 성능 측정(참조 기기) → 배포 → 배포본 실측
4. 결과 보고(측정값) 후 우주 → 좀비 → 디펜스 → 레이스 → 끝말잇기 순서로 3D 확장(각 종 = 로직 분리·같은 점수 시험·성능 측정)
5. 전 게이트 · 배포 · 배포본 전수 확인
